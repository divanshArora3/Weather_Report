# ☀️ Weather Report

**Weather Report** is a responsive web application that allows users to get real-time weather updates for any city around the world. Built using HTML, CSS, and JavaScript, it fetches data from the OpenWeatherMap API and displays key weather parameters in a clean, user-friendly interface.

---

## 🌐 Live Demo

🚀 **View Live:** [Weather Report on GitHub Pages](https://divansharora3.github.io/Weather_Report)  

---

## 📌 Features

- 🌍 **Search by City Name**  
  Users can search for current weather data of any city worldwide.

- 🌡️ **Real-Time Weather Info**  
  Displays temperature, humidity, wind speed, weather condition, and more.

- 🎨 **Dynamic UI Updates**  
  Weather icons and background change according to the weather condition.

- 📱 **Responsive Design**  
  Works smoothly on mobile, tablet, and desktop devices.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/divanshArora3/Weather_Report.git
cd Weather_Report
```
# 🔑 API Key Setup
To use your own OpenWeatherMap API key:

Visit https://openweathermap.org/api and sign up for a free account.
Replace the API key in script.js:

```
const apiKey = "YOUR_API_KEY_HERE";
```
